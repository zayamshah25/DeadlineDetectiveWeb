## Risks and mitigation
1. **Web/mobile scope mismatch:** Course text mentions a mobile Hello World app. **Mitigation:** Obtain explicit instructor approval for web submission; otherwise plan a compliant mobile version.
2. **Merge conflicts:** Multiple members edit the same files. **Mitigation:** Assign branches/tasks, use pull requests, and communicate before merging.
3. **Local setup failure:** Dependencies or Node version differ. **Mitigation:** Document npm setup and test on at least two computers.

## Working agreement
- Communicate progress and blockers in the team group each day during the deadline period.
- Each member works under their own Git identity and makes at least one meaningful commit.
- Commit descriptive changes, avoid committing secrets/databases, and review changes before merging.
- Save genuine screenshots and add evidence only after verifying it.
